# 이건웍스(Leegun Works) — 로고 · 명함 포트폴리오 홈페이지

코딩을 몰라도 직접 관리할 수 있게 만든 홈페이지입니다.
**고칠 파일은 `config.js` 하나뿐입니다.**

---

## 1. 파일이 무슨 역할인지

| 파일 | 하는 일 | 손대도 되나요? |
|---|---|---|
| `config.js` | 이름, 링크, 소개글, 작업 과정, 포트폴리오 목록 | ✅ **여기만 고치면 됩니다** |
| `images/portfolio/` | 작업물 사진을 넣는 폴더 | ✅ 사진 넣는 곳 |
| `index.html` | 화면의 뼈대 | ⚠️ 몰라도 됨 |
| `style.css` | 색과 모양 | ⚠️ 색만 바꿀 땐 맨 위 참고 |
| `script.js` | 화면을 움직이게 하는 부분 | ❌ 건드리지 마세요 |

---

## 2. 링크 넣기 (가장 먼저 할 일)

`config.js` 파일을 열어 `links` 부분의 따옴표 안에 주소를 붙여넣으세요.

```js
links: {
  kakao: "https://pf.kakao.com/_abcdefg",
  instagram: "https://instagram.com/내아이디",
  soomgo: "",     ← 비워두면 버튼이 안 보입니다
  kmong: "",
  threads: "",
},
```

**카카오톡 채널 주소 찾는 법**
1. 카카오톡 채널 관리자센터(`center-pf.kakao.com`) 접속
2. 내 채널 선택 → `채널 관리` → `상세설정`
3. **채널 URL** 항목의 `https://pf.kakao.com/_XXXXX` 주소를 복사

## 3. 새 작업물 올리기 (2단계)

**1단계.** 사진 파일을 `images/portfolio/` 폴더에 넣습니다.
- 파일 이름은 **영어와 숫자**로 지어주세요. (예: `cafe-logo-2026.jpg`) 한글 이름은 오류가 날 수 있습니다.
- 정사각형(1:1) 사진이 가장 예쁘게 나옵니다. 1000×1000 픽셀 정도면 충분합니다.

**2단계.** `config.js` 의 `PORTFOLIO` 목록에서 **★ 표시가 있는 맨 아래 자리**에 한 줄을 추가합니다.

```js
const PORTFOLIO = [
  ... 기존 작업물들 ...

  /* ★ 새 작업물은 이 아래에 한 줄씩 추가하세요 ★ */
  { image: "images/portfolio/cafe-logo-2026.jpg", title: "○○카페 로고", desc: "카페 로고 · 2026" },
];
```

- `image` : 방금 넣은 파일 이름 (앞의 `images/portfolio/` 는 그대로 두세요)
- `title` : 사진 아래 나올 제목
- `desc` : 작은 설명 글 (필요 없으면 `""` 로 비워두세요)

여기에 적은 **순서 그대로** 화면에 나오고, **몇 개를 넣든 전부 다 보입니다.**
"더보기" 버튼으로 숨기지 않으니, 아래에 추가하면 홈페이지에서도 아래로 계속 이어집니다.
(작업물이 아주 많아져서 페이지가 너무 길어지면 그때 다시 조정하시면 됩니다.)

> 줄 끝의 쉼표 `,` 를 빠뜨리면 화면이 안 나옵니다. 한 줄을 통째로 복사해서 내용만 바꾸는 게 가장 안전합니다.

## 4. 인터넷에 올리기 (무료)

GitHub Pages 를 쓰면 서버 비용 없이 공개할 수 있습니다.

1. GitHub 저장소 페이지 → **Settings** 탭
2. 왼쪽 메뉴 **Pages** 클릭
3. `Source` → **Deploy from a branch** 선택
4. `Branch` → **main**, 폴더는 **/ (root)** 선택 후 **Save**
5. 1~2분 뒤 `https://lhj86love.github.io/my-homepage/` 주소로 접속됩니다

나중에 `내이름.com` 같은 개인 도메인을 사서 연결하는 것도 가능합니다 (연 1~2만원대).

## 5. 내 컴퓨터에서 미리 보기

`index.html` 파일을 더블클릭하면 바로 브라우저에서 열립니다.
수정한 뒤에는 새로고침(F5)만 하면 반영됩니다.

---

## 6. 화면이 안 나올 때

거의 항상 `config.js` 의 문장부호 문제입니다. 순서대로 확인해 보세요.

- 따옴표 `"` 를 한쪽만 지우지 않았는지
- 줄 끝 쉼표 `,` 를 빼먹지 않았는지
- 중괄호 `{ }` 나 대괄호 `[ ]` 짝이 맞는지
- 사진 파일 이름의 대소문자와 확장자(`.jpg` / `.png`)가 정확한지

그래도 안 되면 **저장하기 전 상태로 되돌리고** 다시 한 줄씩 바꿔보세요.
