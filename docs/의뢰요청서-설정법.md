# 의뢰 요청서 연결하기

손님이 홈페이지에서 요청서를 보내면
**내 구글시트에 저장되고 + 내 메일로 알림이 오게** 만듭니다.

| | |
|---|---|
| 걸리는 시간 | 약 15분 |
| 비용 | **0원** |
| 가입할 서비스 | **없음** |
| 필요한 것 | 구글 계정 |

코딩은 하지 않습니다. **복사해서 붙여넣기만** 하면 됩니다.

완성되면 이렇게 됩니다:

```
손님          →   홈페이지      →   구글시트        →   내 메일
요청서 작성        보내기 누름        한 줄씩 저장         알림 도착
```

---

## 1단계. 구글 시트 만들기

> 의뢰 내용이 쌓일 공책을 먼저 만드는 단계입니다.

1. 인터넷 주소창에 `sheets.new` 를 입력하고 엔터를 누릅니다
2. 빈 표가 바로 만들어집니다 (아무것도 입력하지 마세요)
3. 왼쪽 위 `제목 없는 스프레드시트` 글자를 누르고 이름을 **이건웍스 의뢰 요청서** 로 바꿉니다

**✅ 여기까지 됐으면** — 빈 표가 열려 있고 왼쪽 위에 방금 지은 이름이 보입니다.
이 창은 닫지 마세요.

---

## 2단계. 코드 붙여넣기

> "요청서가 오면 표에 적고 메일을 보내라"는 지시문을 구글에 넣어주는 단계입니다.

1. 시트 위쪽 메뉴에서 **확장 프로그램 → Apps Script** 를 누릅니다
2. 새 탭이 열리고 짧은 코드가 보입니다
3. 코드 안을 클릭한 뒤 `Ctrl`+`A` (맥은 `⌘`+`A`) → `Delete` 로 **전부 지웁니다**
4. 이 저장소의 **`apps-script/Code.gs`** 파일 내용을 전부 복사해서 붙여넣습니다
5. `Ctrl`+`S` 를 눌러 저장합니다

**✅ 여기까지 됐으면** — 화면 위쪽 `NOTIFY_EMAIL` 줄이 보입니다.
**따옴표 안을 알림 받을 내 이메일 주소로 바꿔주세요.** 이 한 줄이 알림이 갈 곳입니다.

```js
var NOTIFY_EMAIL = '여기에내이메일@gmail.com';   ← 따옴표 안만 바꾸면 됩니다
```

> 이 저장소는 인터넷에 공개되어 있습니다.
> 실제 이메일 주소는 **구글 Apps Script 화면에서만** 바꾸고,
> 저장소 안의 `apps-script/Code.gs` 파일에는 그대로 두세요.
> (그래야 스팸 메일 수집 프로그램에 주소가 노출되지 않습니다.)

---

## 3단계. 인터넷에 연결하기

> 방금 넣은 지시문에 "주소"를 붙여줍니다. 이 주소로 홈페이지가 요청서를 보냅니다.

1. 오른쪽 위 파란 **배포 → 새 배포** 를 누릅니다
2. 왼쪽 위 톱니바퀴 **⚙️** 를 누르고 **웹 앱** 을 고릅니다
3. 아래 표대로 설정합니다
4. 오른쪽 아래 **배포** 를 누릅니다

| 항목 | 고를 값 |
|---|---|
| 설명 | 아무거나 (예: 의뢰 요청서) |
| 다음 사용자로 실행 | **나** |
| 액세스 권한이 있는 사용자 | **모든 사용자** ⭐ |

> ### ⚠️ 가장 많이 틀리는 곳
> 맨 아래 **"액세스 권한이 있는 사용자"** 를 반드시 **모든 사용자** 로 바꿔야 합니다.
> 기본값인 "나"로 두면 손님이 요청서를 보낼 때 실패합니다.

---

## 4단계. 겁나는 경고 통과하기

> 무서운 경고가 뜨지만 정상입니다. 내가 직접 만든 코드라서 나오는 안내입니다.

1. **액세스 승인** 창이 뜨면 **내 구글 계정** 을 고릅니다
2. **"Google에서 확인하지 않은 앱입니다"** 화면이 나옵니다 — 당황하지 마세요
3. 왼쪽 아래 작은 글씨 **고급** `Advanced` 을 누릅니다
4. 아래에 새로 생긴 **○○(안전하지 않음)으로 이동** `Go to … (unsafe)` 을 누릅니다
5. **권한을 고르는 화면**이 나옵니다. **모두 선택** `Select all` 왼쪽 네모 칸을 **체크**합니다
6. 화면을 **아래로 스크롤**해서 **계속** `Continue` 을 누릅니다

> ### ⚠️ 체크를 안 하면 다음으로 못 넘어갑니다
> 네모 칸을 체크하지 않으면 **계속(Continue)** 버튼이 눌리지 않습니다. 여기가 마지막 관문입니다.

요구하는 권한 두 가지는 붙여넣은 코드가 하는 일과 정확히 같습니다.

| 화면에 나오는 권한 | 실제 용도 |
|---|---|
| 구글 시트 보기·수정<br>`See, edit, create… Google Sheets` | 1단계에서 만든 시트에 **의뢰 내용을 한 줄씩 적기** |
| 내 계정으로 메일 보내기<br>`Send email as you` | 의뢰가 오면 **내 메일로 알림 보내기** |

> **"메일을 보낸다"가 불안하다면**
> 코드에서 메일을 보내는 곳은 `NOTIFY_EMAIL` 한 곳뿐입니다.
> 즉 **나에게서 나에게로** 보내는 것이 전부이고, 손님에게는 아무것도 보내지 않습니다.

> **왜 이런 경고가 뜨나요?**
> 구글은 "회사가 검사받지 않은 코드"에 이 경고를 띄웁니다.
> 이 코드는 내가 방금 직접 붙여넣은 것이고, 내 시트와 내 메일에만 접근합니다. 안전합니다.

**✅ 통과하면** — Apps Script 화면으로 돌아가면서 긴 주소가 나옵니다. 그게 5단계에서 복사할 주소입니다.

---

## 5단계. 주소 복사하기

> 이 주소가 홈페이지와 구글을 이어주는 다리입니다.

1. 배포가 끝나면 **웹 앱 URL** 이라는 긴 주소가 나옵니다
2. 옆의 **복사** 버튼을 눌러 복사합니다
3. 메모장이나 카톡 내게쓰기에 잠깐 붙여넣어 두면 안전합니다

**✅ 맞게 복사했는지 확인** — 주소가 `https://script.google.com/` 로 시작하고
**`/exec` 로 끝나면** 맞습니다. `/dev` 로 끝나는 주소는 잘못된 주소입니다.

---

## 6단계. 홈페이지에 주소 넣기

> 마지막 단계입니다. 다리를 홈페이지 쪽에 연결합니다.

1. 깃허브에서 내 저장소 `my-homepage` 를 엽니다
2. 파일 목록에서 **`config.js`** 를 누릅니다
3. 오른쪽 위 **연필 모양 아이콘 ✏️** 을 눌러 편집을 시작합니다
4. `formEndpoint` 라고 적힌 줄을 찾습니다
5. 따옴표 **안쪽** 에 5단계에서 복사한 주소를 붙여넣습니다
6. 오른쪽 위 **Commit changes** → **Commit changes** 를 눌러 저장합니다

```js
이전   formEndpoint: "",

이후   formEndpoint: "https://script.google.com/macros/s/AKfycb....../exec",
```

> ### ⚠️ 자주 하는 실수
> 큰따옴표 `"` 두 개와 맨 끝 쉼표 `,` 를 지우지 마세요.
> **주소만** 따옴표 사이에 넣으면 됩니다.

---

## 다 됐는지 확인하기

홈페이지에 들어가서 **본인이 직접** 요청서를 아무 내용이나 넣고 보내보세요.

- [ ] 화면에 초록색으로 **"요청서를 보냈습니다"** 가 뜬다
      (회색 "준비 중" 안내가 사라졌는지도 확인)
- [ ] **구글 시트** 에 방금 넣은 내용이 한 줄 생겼다
- [ ] **메일** 로 `[의뢰 요청서] ...` 제목의 알림이 왔다 (안 오면 스팸함 확인)

세 개가 전부 되면 끝입니다. 앞으로 관리할 것은 없습니다.

---

## 잘 안 될 때

| 이런 증상이면 | 여기를 확인하세요 |
|---|---|
| "전송에 실패했습니다" | **3단계** 의 액세스 권한이 **모든 사용자** 인지 확인 |
| 버튼이 계속 잠겨 있음 | **6단계** 의 주소가 `/exec` 로 끝나는지 확인 |
| 시트에 안 쌓임 | 스크립트를 **시트의 확장 프로그램 메뉴** 에서 연 것이 맞는지 확인 |
| 메일이 안 옴 | 스팸함 확인 → `NOTIFY_EMAIL` 주소 오타 확인 |
| 홈페이지가 안 바뀜 | 저장 후 1~2분 기다린 뒤 `Ctrl`+`F5` 로 새로고침 |
| 코드를 고쳤는데 그대로 | **배포 → 배포 관리 → 연필 → 버전: 새 버전** 으로 다시 배포<br>(주소는 안 바뀌니 `config.js` 는 그대로 두세요) |

## 카카오톡으로도 알림 받기

카카오톡으로 요청서를 직접 받으려면 카카오 비즈니스 채널 심사와
**건당 유료인 알림톡**이 필요해서, 비용 0원 조건에는 맞지 않습니다.

대신 **휴대폰 Gmail 앱의 알림을 켜두시면** 요청서가 올 때 카톡처럼 바로 알림이 옵니다.
실질적으로 같은 효과이고 비용은 0원입니다.
