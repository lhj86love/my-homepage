# 의뢰 요청서 연결하기 (약 15분, 비용 0원)

손님이 홈페이지에서 요청서를 보내면
**① 구글시트에 자동으로 쌓이고 ② 이메일로 알림이 오게** 만드는 방법입니다.

- 비용: **0원** (구글 계정만 있으면 됩니다)
- 건수 제한: **없음** (메일 알림만 하루 100건까지 — 사실상 무제한)
- 가입할 서비스: **없음** (이미 쓰시는 구글 계정 그대로)

> 어렵게 느껴지시면 이 문서를 그대로 따라만 해주세요.
> 코드를 이해하실 필요는 전혀 없고, **복사해서 붙여넣기만** 하시면 됩니다.

---

## 1단계. 구글 시트 만들기

1. 브라우저에서 **https://sheets.new** 접속 (빈 시트가 바로 만들어집니다)
2. 왼쪽 위 "제목 없는 스프레드시트"를 눌러 이름을 **`이건웍스 의뢰 요청서`** 로 바꿉니다

이 시트에 앞으로 의뢰 내용이 한 줄씩 쌓입니다.

---

## 2단계. 스크립트 붙여넣기

1. 방금 만든 시트 화면 위쪽 메뉴에서 **확장 프로그램 → Apps Script** 클릭
2. 새 탭이 열리고 `function myFunction() { }` 같은 코드가 보입니다
3. **그 안의 내용을 전부 지웁니다** (Ctrl+A 누르고 Delete)
4. 이 저장소의 **`apps-script/Code.gs`** 파일을 열어 **전체 복사**해서 붙여넣습니다
5. 붙여넣은 코드 윗부분에서 알림 받을 메일 주소를 확인합니다

   ```js
   var NOTIFY_EMAIL = 'lhj86love@gmail.com';   ← 본인 메일이 맞는지 확인
   ```

6. 저장 버튼(💾 또는 Ctrl+S)을 누릅니다

---

## 3단계. 인터넷에 연결하기 (배포)

1. 오른쪽 위 파란 **배포 → 새 배포** 클릭
2. "유형 선택" 옆 **톱니바퀴 ⚙️** 를 누르고 **웹 앱** 선택
3. 아래처럼 설정합니다

   | 항목 | 선택할 값 |
   |---|---|
   | 설명 | 아무거나 (예: 의뢰 요청서) |
   | 다음 사용자로 실행 | **나** |
   | 액세스 권한이 있는 사용자 | **모든 사용자** ⭐ 중요 |

4. **배포** 클릭
5. **"액세스 승인"** 창이 뜨면 → 본인 구글 계정 선택
6. **"Google에서 확인하지 않은 앱입니다"** 경고가 나옵니다
   → 왼쪽 아래 **고급** → **(안전하지 않음)으로 이동** 클릭
   → **허용**

   > 내가 직접 만든 스크립트라서 나오는 경고입니다. 정상입니다.

7. 마지막에 나오는 **웹 앱 URL** 을 복사합니다
   `https://script.google.com/macros/s/AKfycb....../exec` 형태입니다

---

## 4단계. 홈페이지에 주소 넣기

`config.js` 파일을 열어 아래 부분에 방금 복사한 주소를 붙여넣습니다.

```js
formEndpoint: "https://script.google.com/macros/s/AKfycb....../exec",
```

저장하면 끝입니다. 요청서 아래의 "준비 중" 안내가 사라지고 전송 버튼이 켜집니다.

---

## 5단계. 잘 되는지 확인

1. 홈페이지 의뢰 요청서에 **본인이 직접 아무 내용이나** 넣고 보내봅니다
2. 확인할 것 3가지
   - 화면에 **"요청서를 보냈습니다"** 초록색 안내가 뜨는지
   - **구글 시트**에 방금 넣은 내용이 한 줄 생겼는지
   - **이메일**로 `[의뢰 요청서] ...` 제목의 메일이 왔는지

세 가지가 모두 되면 완료입니다.

---

## 카카오톡으로도 알림 받기 (선택)

메일 알림만으로 충분하지만, 카톡으로도 즉시 받고 싶으시면
**Gmail 앱 알림을 켜두시는 방법**이 가장 간단합니다.
(카카오톡으로 직접 보내려면 카카오 비즈니스 채널 심사와 유료 알림톡이 필요해서,
비용 0원 조건에는 맞지 않습니다.)

---

## 잘 안 될 때

| 증상 | 확인할 것 |
|---|---|
| "전송에 실패했습니다" | 3단계의 **액세스 권한이 "모든 사용자"** 인지 다시 확인 |
| 시트에 안 쌓임 | 스크립트를 **시트의 확장 프로그램 메뉴**에서 연 것이 맞는지 확인 |
| 메일이 안 옴 | 스팸함 확인 → `NOTIFY_EMAIL` 주소 오타 확인 |
| 코드를 고친 뒤 반영 안 됨 | **배포 → 배포 관리 → 연필 아이콘 → 버전을 "새 버전"** 으로 다시 배포 |

> 코드를 수정했을 때는 저장만으로는 반영되지 않고 **다시 배포**해야 합니다.
> 이때 주소(URL)는 바뀌지 않으니 `config.js` 는 그대로 두시면 됩니다.
